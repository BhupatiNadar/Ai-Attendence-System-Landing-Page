# 🚀 AI Attendance System - Landing Page

A modern and responsive landing page for the AI Attendance System, showcasing intelligent attendance tracking through Face Recognition, Voice Verification, QR-Based Class join, and Cloud Integration.

Built with Flask, HTML, CSS, JavaScript, and Jinja templates.

---

## 🌐 Live Demo

https://ai-attendence-system-landing-page.vercel.app

---

## 📖 About

The AI Attendance System Landing Page serves as the public-facing website for the AI Attendance platform.

It highlights the project's features, workflow, technology stack, and benefits for educational institutions and organizations looking to automate attendance management using AI-powered biometric authentication.

## ⚙️ Installation

### Clone Repository

```bash
git clone https://github.com/BhupatiNadar/Ai-Attendence-System-Landing-Page.git
```

```bash
cd Ai-Attendence-System-Landing-Page
```

### Create Virtual Environment

#### Windows

```bash
python -m venv venv
venv\Scripts\activate
```

#### Linux / Mac

```bash
python3 -m venv venv
source venv/bin/activate
```

### Install Dependencies

```bash
pip install -r requirements.txt
```

### Run Application

```bash
python app.py
```

or

```bash
flask run
```
